# Xojo Custom Desktop Button Control

This repository contains the code for a custom button control built for Xojo Desktop applications using the `DesktopCanvas`.

## Requirements

*   Xojo (a recent version is recommended)
*   Xojo Desktop Project

## How to Use

1.  Clone or download this repository.
2.  Open your Xojo Desktop project.
3.  Drag the `CanvasButton.xojo_code` file from the repository into your Xojo project's Navigator.
4.  Drag the `CanvasButton` control from the Library onto one of your windows or containers.
5.  Implement the `Pressed` event handler for the button instance to define what happens when the button is clicked.
